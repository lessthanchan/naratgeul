수집하는 정보

과일키보드는 입력하는 글, 키 입력 패턴, 개인정보를 포함한 어떤 데이터도 수집, 저장, 분석, 전송하지 않습니다. 앱과 키보드 확장은 인터넷에 연결하지 않으며 분석, 광고, 추적 도구가 없습니다.

전체 접근 허용

'전체 접근 허용'은 키를 누를 때 진동(햅틱)을 내는 데에만 쓰입니다. iOS가 전체 접근을 켠 키보드에만 진동을 허용하기 때문이며, 켜지 않아도 입력과 클릭음은 그대로 동작합니다.

기기 안 저장 정보

햅틱 강도, 키보드 높이, 숫자 자판 0 옆 버튼 기호 같은 설정은 사용자의 기기 안에만 저장되며 외부로 전송되지 않습니다.
